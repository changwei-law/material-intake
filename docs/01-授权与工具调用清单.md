# 授权与工具调用清单

> 适用版本：material-intake 0.2.15 ｜ 最后更新：2026-10-06
> 本清单由技能内 `material-intake/references/依赖与注意事项.md` 第六节与各脚本实际调用点逐条核对而成；两处如有出入，以技能内文件与脚本行为为准。

装这个技能之前，你只想知道三件事：**它要什么权限、它调用什么、它把你的东西写到哪**。本文按这三件事分别列清。

---

## 一、结论先行

| 问题 | 答案 |
|---|---|
| 不给任何权限能用吗 | **能**。台账、查重、扫描、归档、归档登记全部可用，这是零授权模式 |
| 必须给的权限有几项 | **零项**。其余十三项都是按需触发，用到哪一项才要哪一项 |
| 会联网吗 | 只有钉钉通道联网，不配置就完全不出网 |
| 有第三方依赖吗 | 没有。Python 脚本只用标准库，不需要 pip 安装任何包 |
| 会改动系统吗 | 有 3 项会：Windows 通知总开关、通知身份注册、日历订阅开机自启。三项都可回退，执行前须经同意 |
| Windows 与 macOS 功能一样吗 | **不一样**。macOS 一条命令闭环（可读回、可撤销、支持周期日程）；Windows 用五条通道拼出，无周期日程、无待办清单等价物，`.ics` 导入的条目不能按锚点撤销。见 [04-平台差异对照.md](04-平台差异对照.md) |
| 钉钉能直接用吗 | **不能**。前提是你在一个钉钉组织里有权限：要么让组织**管理员放行**，要么**自建一个组织**（自己即主管理员）。见 [05-钉钉通道开通前提.md](05-钉钉通道开通前提.md) |

---

## 二、需要的授权（十三项，按需触发）

| # | 授权项 | 何时会要 | 在哪里放行 | 拒绝后 |
|---|---|---|---|---|
| 1 | 日历（**完全访问**） | macOS 首次写日程 | 系统设置 → 隐私与安全性 → 日历 → 勾选当前应用，选「完全访问」 | 写不进日历，且查重与撤销同时失效；脚本直接拒绝执行并给出放行路径 |
| 2 | 提醒事项（**完全访问**） | 同上 | 系统设置 → 隐私与安全性 → 提醒事项 | 分档提醒写不进去 |
| 3 | 文件与文件夹 | 读桌面／文稿／下载等受保护目录 | 系统设置 → 隐私与安全性 → 文件与文件夹；跨目录批量操作需「完全磁盘访问权限」 | 扫描报错或列出被跳过的路径，其余目录照常 |
| 4 | 宿主沙箱可写范围 | WorkBuddy／千问办公归档到工作区以外 | 宿主设置里放行该目录 | 写入被宿主拦下 |
| 5 | Windows 日历访问 | Windows 直写本机日历 | 设置 → 隐私和安全性 → 日历 → 允许应用访问日历 | 本机日历后端报错并给替代通道；`.ics` 导出不需要授权 |
| 6 | PowerShell 执行策略 | 运行 `.ps1` | `-ExecutionPolicy Bypass -File` 单次放行，不必改全局策略 | 脚本被策略拦下 |
| 7 | macOS Gatekeeper | 首次双击 `.command` | 文件右键 → 打开；或 系统设置 → 隐私与安全性 → 仍要打开 | 双击无反应 |
| 8 | Windows SmartScreen | 首次运行下载来的脚本 | 选择「仍要运行」 | 脚本被拦下 |
| 9 | 宿主的库外读取确认 | 读取工作区以外的路径 | 宿主弹窗确认 | 该次读取失败 |
| 10 | **Windows 通知总开关**（系统级） | 需要到点弹通知时 | 设置 → 系统 → 通知 → 打开总开关（注册表 `HKCU\…\PushNotifications\ToastEnabled` 置 `1`） | ⚠ 打开后**所有应用**的通知都会弹，不只是本技能 |
| 11 | **提醒身份注册**（注册表 + 开始菜单快捷方式） | 首次使用通知提醒 | `win_remind.ps1 install` | 通知无法以本技能身份投递 |
| 12 | **本机日历订阅服务**（常驻本地 HTTP + 开机自启） | 需要桌面日历客户端订阅时 | `calendar_feed.ps1 install` | 客户端订阅不到；服务只监听 `127.0.0.1`，不出网 |
| 13 | **钉钉通道**（组织权限 + 凭据 + 内容出网） | 需要手机钉钉提醒，或钉钉日历与待办时 | **先解决组织权限**：由所在组织**管理员放行**（管理后台配开发者权限，或提交审批单由管理员批准），或**自建一个钉钉组织**（自己即主管理员）；再自备机器人 webhook（群机器人另需群权限） | ⚠ 日程标题与时间会上传钉钉服务器；**无组织权限则通道不可用**，详见 [05-钉钉通道开通前提.md](05-钉钉通道开通前提.md) |

**第 10、11、12 项属系统改动**，执行前必须先说明「改什么、影响谁、怎么回退」，得到使用者同意再动；第 13 项属内容出网，涉密案件不要用。

**不需要授权的情形**：归档写入本技能自己的白名单目录、`.ics` 导出后手动导入、纯台账与查重（前提是文件系统允许读）。

## 三、调用的工具与接口

### 3.1 随包运行的外部程序

| 工具 | 平台 | 调用时机 | 是否必需 |
|---|---|---|---|
| `python3`（3.9+） | 全平台 | 台账、查重、扫描、归档、`.ics` 导出、日程预演 | 必需，脚本仅用标准库 |
| `bin/lr_ek` | macOS | 写／读／删系统日历与提醒事项 | 日程功能必需，随包提供 arm64 二进制 |
| `swiftc` | macOS | 仅当二进制缺失或 `lr_ek.swift` 比二进制新时自动重编译 | 非必需（有 Xcode 命令行工具即可） |
| `uname -m` | macOS | 探测 CPU 架构，决定编译 target | 非必需 |
| `powershell.exe`（5.1） | Windows | 本机日历、系统通知、日历订阅、钉钉四个后端 | Windows 侧日程功能必需 |
| `dws` / `dws-core` | Windows | 钉钉日历与待办（可选通道） | 非必需，需自行 `npm i -g dingtalk-workspace-cli` |

技能本体**不包含**任何第三方 Python 包或二进制依赖。OCR、视觉识别、docx／xlsx／PDF 解析、正式文书排版、法条核验属**外接能力**，由宿主或使用者自备，不装也不影响台账与归档。

### 3.2 调用的系统接口

| 平台 | 接口 | 用途 |
|---|---|---|
| macOS | EventKit（经 `lr_ek`） | 日历事件与提醒事项的读写、周期性事件、按锚点精确撤销 |
| Windows | `Windows.ApplicationModel.Appointments` | 直写系统日历存储，无需手工导入、可读回与撤销 |
| Windows | `Windows.UI.Notifications` | 到点弹系统通知 |
| Windows | ScheduledTasks 模块 | 注册日历订阅的开机自启、钉钉提醒的一次性任务 |
| Windows | 注册表 `HKCU` | 通知身份 `AppUserModelId`、通知总开关状态检查 |
| Windows | `Invoke-RestMethod` | 钉钉机器人 webhook 投递 |
| 全平台 | 本地 HTTP（`http.server`） | 仅监听 `127.0.0.1:8799`，把各任务日历合并成一份 `agenda.ics` 供桌面日历客户端订阅 |

### 3.3 网络行为

| 通道 | 目标 | 内容 | 是否默认开启 |
|---|---|---|---|
| 日历订阅 | `127.0.0.1:8799`（仅本机回环） | 日程清单合并结果 | 否，需 `install` |
| 钉钉 | `oapi.dingtalk.com`（HTTPS，HMAC-SHA256 加签） | 日程标题、时间、提醒文案 | 否，需自备凭据 |

除上述两处，脚本内没有任何网络请求代码。**不启用钉钉，就没有任何内容离开本机。**

### 3.4 会写入或改动的位置

| 位置 | 内容 | 可否回退 |
|---|---|---|
| 工作区目录（`待处理/`、`代办录入/`、`已处理/`、`待归档/`、台账） | 材料副本、录入台账、归档台账 | 用户自行管理，脚本不删除 |
| 配置文件（默认 `~/.material-intake/config.json`） | 工作区路径、归档白名单 | 直接编辑或删除 |
| macOS 系统日历与提醒事项 | 带「来福ID: 锚点」备注的条目 | 按锚点撤销，先预演再落盘 |
| Windows 系统日历 | 同上（锚点算法一致） | 同上 |
| `%USERPROFILE%\.material-intake\` | 钉钉凭据、订阅输出、日志 | 删除目录即可 |
| 注册表 `HKCU\SOFTWARE\Classes\AppUserModelId\MaterialIntake.Reminder` 与开始菜单快捷方式 | 通知投递身份 | `win_remind.ps1 uninstall` |
| 计划任务「材料代办录入-日历订阅」 | 开机自启的本地订阅服务 | `calendar_feed.ps1 uninstall` |
| 计划任务（钉钉提醒） | 到点投递的一次性任务 | `dingtalk_remind.ps1 clear` |

脚本自身的写入边界：**不删除原件、不覆盖同名文件、不写归档白名单以外的路径**。归档命令缺省只预演，加 `--apply` 才落盘。

## 四、可直接转发给使用者的一段话

> 这个技能不给任何权限就能用——台账、查重、归档、登记都能跑。只有在你需要「自动写日历」「到点弹提醒」时，才需要按需授权：macOS 是日历和提醒事项的**完全访问**（不能被"仅写入"替代），Windows 是日历访问与通知总开关。三项会改动系统设置（通知总开关、通知身份、订阅自启），我会先说明改什么、怎么退，你同意再动。唯一的联网通道是钉钉提醒，需要你自己配凭据，涉密材料不要走。
