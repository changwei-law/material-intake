# 安装与首次授权引导（给人看的版本）

> 适用版本：material-intake 0.2.15 ｜ 最后更新：2026-10-06
> 技能内另有一份同名文档 `material-intake/references/安装与授权引导.md`，那是**给智能体执行的指令**；本文是**给人看的说明书**，两者同源。

装这个技能不需要你会命令行。整个安装是「复制一个文件夹」，授权是「在系统设置里点几下」，最多十分钟。

---

## 一、安装：复制一个文件夹

| 你在用哪个宿主 | 把 `material-intake` 文件夹复制到 |
|---|---|
| Codex | `~/.codex/skills/`（Windows：`%USERPROFILE%\.codex\skills\`） |
| WorkBuddy | `~/.workbuddy/skills/`（旧版 `~/.codebuddy/skills/`） |
| 千问办公（QwenWork） | `~/.qwenworkcn/skills/` |
| DSH 桌面版 | 应用数据目录下的 `harness/skills/` |

复制完，文件夹结构应是 `…/skills/material-intake/SKILL.md`。**装完先跑一次体检**：

```bash
python3 material-intake/scripts/material_intake.py doctor
```

Windows 上把 `python3` 换成 `python`。看到「配置完整，可以开工」即装好。

**会看到什么、要多久**

| 步骤 | 你会看到 | 大概耗时 |
|---|---|---|
| 复制文件夹 | 目标目录出现 `material-intake` | 10 秒 |
| 跑 `doctor` | 终端打印宿主、Python 版本、配置状态 | 5 秒 |
| `init-config` 生成配置 | 生成 `~/.material-intake/config.json` | 10 秒 |
| 填配置（工作区路径、归档白名单） | 用任意文本编辑器改两行路径 | 2 分钟 |
| 按需授权 | 系统设置面板里勾选应用 | 每项 1 分钟 |

## 二、授权分四档，一次只需要给一档

| 档 | 什么时候需要 | 要给什么 | 不给会怎样 |
|---|---|---|---|
| **装机档** | 刚装好 | **什么都不用给** | 台账、查重、归档、登记照常可用 |
| 台账档 | 材料在桌面／文稿／下载等受保护目录 | macOS 文件与文件夹（必要时完全磁盘访问） | 把材料先复制进工作区，照样能录 |
| 日程档 | 第一次要把期限写进日历 | macOS 日历 + 提醒事项，**必须完全访问** | 改用 `.ics` 导出，自己导入日历 |
| 通知档 | 要「到点弹提醒」 | Windows 通知总开关 + 通知身份；可选日历订阅、钉钉 | 改用 `.ics` 导到手机日历 |

**装机档一定要先说明白：这一步不需要给任何权限。** 避免让人以为不给权限就用不了。

## 三、每一项授权，四句话讲清

**① 日历与提醒事项（macOS）**

> 需要把日历和提醒事项权限给到当前应用，我才能把开庭、举证期限写进你的日历并按 T-7／T-3／T-1／当天提醒。
> 点这里：系统设置 → 隐私与安全性 → 日历，勾选当前应用，权限选**完全访问**；提醒事项同理。
> 「仅写入」不行——那样我既查不了重、也撤不掉写进去的条目，脚本会直接拒绝写入。
> 不想给也行：日程改用 `.ics` 导出，你自己导入。改完告诉我，我重跑 `doctor` 复检。

**② 文件与文件夹（macOS）**

> 材料在桌面或文稿目录时，系统默认不让应用读。请到 系统设置 → 隐私与安全性 → 文件与文件夹 允许访问；材料分散在多个受保护目录时可能要开「完全磁盘访问权限」。
> 不想开也行：把材料复制进工作区，我照样能录。

**③ Windows 通知总开关（系统级改动）**

> 这条会改系统设置：从静默改成弹通知，**所有应用的通知都会开始弹**，不只是本技能。
> 如果你原本是有意关掉通知的，我们就不开，改用 `.ics` 导到手机日历。回退方法是把开关关回去。

**④ 通知身份注册（仅 Windows）**

> 需要在注册表写一个通知身份并建一个开始菜单快捷方式，通知才能以本技能身份投递。回退命令是 `uninstall`，不留残余。

**⑤ 钉钉通道（有两道门：组织权限 + 内容出网）**

> 这条要先过一道"资格"关：**钉钉通道要求你在一个钉钉组织里有权限**。两条路——① 用现有组织（比如单位），需要该组织**管理员放行**（管理后台给你配开发者权限，或你提交审批单由管理员批准）；② 你自己在钉钉客户端「组织架构 → 创建或加入企业/团队」**建一个组织**，你就是主管理员，不需要任何人审批。另外，群机器人是群权限问题，`dws` 日历待办是组织权限问题，两者要分开看。
> 过了资格关还要接受一件事：这条会把**日程标题和时间上传钉钉服务器**，标题含案号、法院、当事人时属案件信息外发，**涉密案件不要用**。凭据只存本机，不随包分发。
> 不想用或走不通也行：改用 `.ics` 导到手机日历，台账与归档不受影响。
> 开通步骤、验证命令与失败排查见 [05-钉钉通道开通前提.md](05-钉钉通道开通前提.md)。

## 四、复检：每给完一项，立刻验证

```bash
python material_intake.py doctor      # 归档侧：配置与目录
python schedule_write.py doctor       # 日程侧：读写通道（macOS）
```

Windows 侧另有 `win_calendar.ps1 doctor`、`win_remind.ps1 doctor`、`calendar_feed.ps1 status`。

复检完把结果读给使用者听（通过／未通过、还差什么），不要留到下次。

## 五、常见卡住的地方

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 双击安装脚本没反应 | macOS Gatekeeper 拦下未签名脚本 | 右键 → 打开；或 系统设置 → 隐私与安全性 → 仍要打开 |
| 下载来的 `.ps1` 被拦 | Windows SmartScreen | 选择「仍要运行」 |
| 点了用日历，系统却没有任何弹窗 | 该应用已经拒绝过一次；或应用 `Info.plist` 缺用途说明键（macOS 14 起会静默拒绝） | 见技能内 `references/安装与授权引导.md` 第七节逐步排查 |
| `doctor` 报未授权，但设置里显示已授权 | 授权档位是「仅写入」 | 改选「完全访问」后重跑 `doctor` |
| 提示找不到 Python | Python 不在 PATH，或 Windows 商店占了名 | 用宿主内置运行时，或用 `-Python` 指定真解释器 |
| 提示目标目录不在允许范围 | 归档白名单没配 | 把目录加入配置里的 `allowed_roots`，不要绕开校验 |
| 提示同名文件已存在 | 防覆盖设计 | 换带日期或版本后缀的新名 |
| 钉钉通道报无权限／授权失败 | 组织权限没解决 | 按 [05-钉钉通道开通前提.md](05-钉钉通道开通前提.md)：让所在组织管理员放行，或自建一个组织、自己做主管理员 |
| Windows 上 `schedule_write.py list`／`rm` 不可用 | 这两个子命令依赖 EventKit，Windows 按设计不支持 | 改用 `win_calendar.ps1 list`／`rm`、`win_remind.ps1 list`／`clear`；`.ics` 导入的只能在日历客户端里手工删 |
